One Question. Three Approaches.

Built a small RAG demonstration to understand how external knowledge is supplied to an LLM and how orchestration differs between explicit Python code and LangChain Expression Language. main.py asks the same question three ways.

Direct LLM

Direct Gemini — Without Retrieval

The question goes directly to Gemini without retrieving documents from the project's knowledge base.

  1. Question
  2. Gemini
  3. Answer

Simple LLM integration, but no access to the external knowledge base through this workflow.

Explicit RAG

RAG with Explicit Python Orchestration

Retrieves relevant Pinecone chunks, builds a context-aware prompt, and invokes Gemini through explicit Python calls using LangChain components.

  1. Question
  2. Retrieve relevant chunks
  3. Build context-aware prompt
  4. Gemini
  5. Answer

RAG enriches the prompt with external context without retraining the model.

LCEL-based RAG

RAG with LangChain Expression Language

Composes retrieval, prompt-building, model invocation, and output parsing into a reusable LCEL pipeline.

  1. Question
  2. Retriever
  3. Prompt
  4. Model
  5. Output parser

RunnablePassthrough.assign and itemgetter supply context to the prompt template and chat model; StrOutputParser returns text.

LCEL changes composition and readability. It does not inherently improve answer quality or execution speed.

From Documents to Searchable Knowledge
  1. Original text / notesLocal source text
  2. Character-based chunking1,000-character target · zero overlap
  3. Google embeddingsgemini-embedding-001 · 1,536 dimensions
  4. Pinecone vector indexDense · cosine similarity · AWS us-east-1

ingestion.py uses CharacterTextSplitter; long paragraphs can exceed the chunk target. At query time, both RAG workflows request up to three chunks (k=3) from this index.

Beyond the Happy Path
  • .env.example for configuration; Git exclusions for credentials and local files.
  • Portable file paths and locked dependencies in uv.lock.
  • Existing Pinecone indexes stay untouched unless an explicit --reset-index is supplied.
  • Eight offline tests covering data flow and ingestion safeguards.

An educational implementation with attention to engineering quality. Offline checks do not validate live APIs or answer quality; a live API smoke test of the cleaned-up version is still pending.

RAG changes the context available to the model. LCEL changes how the workflow is composed.

Retrieval can provide useful external information, but answer quality still depends on the relevance of the retrieved context and the model's behavior. Framework abstractions simplify implementation without removing the need for architectural judgment.

Understanding agent orchestration beyond framework abstractions.

Explored AI agent orchestration through two practical Python implementations: a Gemini-powered job-search agent using LangChain and Tavily, and an explicit ReAct-style tool-calling loop with custom tools. An educational reference for how LLMs use external tools, maintain context, process observations, and produce final responses.

01 Framework-managed

LangChain-Powered Job Search Agent

A Gemini-powered agent using LangChain’s create_agent() and Tavily Search to discover AI engineering opportunities in Bengaluru. LangChain manages tool execution and returns a structured answer with source URLs.

  1. User query
  2. LangChain create_agent()
  3. Tavily Search
  4. Structured response

02 Explicit orchestration

Custom ReAct-Style Agent Loop

Uses LangChain’s .bind_tools() with custom Python tools for product-price lookup and discount calculations. Manually dispatches tool calls, appends observations to message history, and stops on a final answer or an iteration limit.

  1. Model decision
  2. Tool call
  3. Tool result
  4. Repeat or final answer

Tool observations feed back into the next model decision.

Frameworks accelerate implementation. Understanding the underlying agent loop enables better engineering decisions.

Both examples use LangChain interfaces with Gemini; the second makes orchestration explicit.
